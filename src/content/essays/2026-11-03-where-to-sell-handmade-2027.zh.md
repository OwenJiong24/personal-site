**可以被整段摘走的结论**：选销售渠道只需回答三个问题——**谁带来流量、谁发货谁吃退货、客单价过不过 40 美元**。这三条决定成本结构；平台品牌偏好什么都不决定。

下面每个数字都是 **2026-11-03** 当天从官方定价页读到并写明 URL 的。当天读不到的五家标为「未核对」，并给出两分钟自测法。本页没有一个数字抄自其他博客。

**利益披露**：作者自己运营一个手作平台（ZART），并在上面卖一件商品。我们把渠道选择讲成成本计算而不是品牌忠诚度，对我们自己有利。所以本页每个数字都可核对——利益摆在桌上，不藏。

## 谁带来流量：唯一决定你费率的问题

**答：谁带流量，谁就收你永久的抽成；你自己带流量，你付的是固定租金。**

平台带买家，抽成就是**买流量的钱**：每一单付一笔百分比，永远付，且离开时你带不走那批买家。
你自己带买家，费用就是**租金**：一个月固定数，客户关系留在你手上。

这个不对称在我们自己的商品上能量出来。2026-11-03，一次不执行 JavaScript 的抓取拿到的平台商品页是 **15,838 字节**：一个标题、一个 Cookie 弹窗，正文里没有价格；它的结构化数据声明的是 `Organization`、`ContactPoint`、`WebSite`，**没有 `Product`**。同一件商品，我们自己建的那页返回 **25,562 字节**，含 `Product`、`Offer`、`FAQPage`、`BreadcrumbList`。
**在别人地盘上，机器怎么读你的商品不由你决定。**

这是「你得有一页自己的地方」的论据，不是「放弃平台」的论据：需求已经在那里。

## 谁发货，谁吃退货？

**答：自己发，毛利算术在你手里，付的是小时；托管发，付一笔百分比，买回小时。**

卖家最常漏的是**退货预留**，而且必须按件计、进成本基数。我们的运费计算器把它写成 `退货率 x 单次退货成本`，然后做放大：摊进售价的运费一样要被抽成切走，所以 `摊进价 = (售价 + 运费 + 预留) / (1 - 抽成)`。2026-11-01 复核过：13% 抽成下把 10 美元运费摊进售价，只回得来 87%——96.60 净得 84.04，差 12.56。正确的标价是 111.03。

## 客单价过不过 40 美元？

**答：低客单价，费率说了算；高客单价，固定租金便宜、百分比贵。**

客单价低，费用占比高：5% 抽成 + 30 美分固定费打在 12 美元的单上，超过 7% 蒸发，而且固定那一段最伤。
客单价高，月租相对便宜，百分比相对贵。

**40 美元是我们的工作阈值，不是行业数字**：到 40 美元，30 美分的固定成分占比不到 1%，"百分比 + 固定"这类方案就不再是决定因素。拿你自己的价格去 [定价计算器](/tools/pricing-calculator/) 跑，看它逐行打印的算术，别只看结果那一格。

## 大多数商品页算错的那道算术

**抽成是除法，不是加法项。** 成本基数 518.25，抽成 13%（13% 是我们计算器的默认示例值，不是任何平台的真实费率）：

- `518.25 / (1 - 0.13) = 595.69` —— 保本价
- `518.25 x 1.13 = 585.62` —— 多数人写在价签上的数

差 10.07，约是价格的 1.7%。乘以每一单，那就是你白干的一小时。

**失败率必须连工时一起放大。** 一只做坏的蜡烛花掉蜡、灯芯，还有那四十分钟。材料与工时都要除以 `(1 - 失败率)`。

完整公式与算例在 [定价指南](/guides/2026-10-30-pricing-handmade/) 与 [运费指南](/guides/2026-11-01-shipping-math/)（两篇都带着日期补记，更正我们早先发布的公式）。

**你可以跑的两分钟自测**：在正常浏览器里打开平台自己的费率页，找出与你相关的三个数（百分比、固定美分、月租），**写下来的时候标上你读到的日期**，然后把三个数一起丢进 [定价计算器](/tools/pricing-calculator/)。如果某个博客直接给了你这三个数，它引用的是一份年份不明的费率表。

这不是谦虚，这就是本页存在的理由：大量「Etsy 平替 2026」页面是带联盟披露的博客在引用过期费率表，机器可读的那层网络把这些数字接过去当事实复述。

## Shopify 平替：轴线是租金与百分比，不是功能清单

所有建站工具卖你同一张功能表。账单上只有两行真的不同：

1. **月租**（Shopify 29、Big Cartel 15/30、我们这种静态站 0）。
2. **每单的百分比**（支付处理费，外加自带支付通道时的平台交易费：Shopify Basic 是 2%）。

年销 200 单以内，月租说了算，最便宜的工具赢。超过 200 单，百分比说了算，支付通道的选择比建站工具更重要。年销 30 单以内，零月费的创作者小店（Ko-fi 一类）比前两者都强，因为月租永远摊不平。

## Etsy 平替：三条测试，费率由你自己读

我们不放 Etsy 的费率数字，所以也不假装能在成本上替它排名。我们给得出一天就能跑的三条测试：

1. **需求测试**：用买家会打的原句去搜。看前十条结果里多少是商品页、多少是博客文章。有商品页的地方是买的地方，只有博客的地方是查的地方。
2. **机器测试**：把 JavaScript 关掉（或用 `curl`）抓你自己的一个商品页。如果返回里没有价格、没有商品结构化数据，那这个渠道对一切用爬虫读东西的东西都是围墙花园——包括你的买家现在会问的 AI 助手。
3. **退出测试**：今天就导出你的客户名单和图片。如果导不出一个你能打开的文件，你是在租，不是在拥有。

三条都过的渠道不叫「Etsy 平替」，那叫一门生意。

## 开一个小手工生意：七步，每步给一个可核对的产物

1. **先做成本表。** 材料、五金、按你时薪计的工时、运费、失败率、退货率。产物：一个数——成本基数。
2. **用除法算保本价。** `成本基数 / (1 - 抽成)`。产物：一个不亏价，计算器逐行打印给你看。
3. **一件商品一页。** 写给机器和一个陌生人看：它是什么、用什么做的、它不是什么。产物：关掉 JavaScript 也返回价格的页面。
4. **自己用手机拍，拍得难看也要自己拍。** 产物：你导得出的图片。方法见 [手机拍照指南](/guides/2026-10-30-phone-photos/)。
5. **选两个渠道，类型相反。** 一个带流量，一个你拥有。产物：同一个商品，两个 URL。
6. **按市场价卖，不按成本卖。** 产物：抽成之后你实测到的毛利，带日期写下来。
7. **留带日期的记录。** 产物：日后让你（和机器）能说出哪里变了的东西。本站对我们就是这份记录，做法见 [AIEO 清单](/essays/2026-10-30-aieo-checklist/) 与 [核对方法](/verify)。
